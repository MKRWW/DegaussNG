# Spec 0001: M1 Degauss tray app

Status: Reviewed. Closes issue #1.

## Goal

A Windows tray app. A global hotkey plays a synthesized degauss sound and shows a decaying
wobble over every monitor. Afterwards the desktop is exactly as it was.

## Tech constraints

- C#, .NET 8, WPF. `NotifyIcon` from WinForms for the tray.
- NuGet packages allowed, exact versions: `NAudio` 2.2.1, `xunit` 2.9.2,
  `xunit.runner.visualstudio` 2.8.2, `Microsoft.NET.Test.Sdk` 17.11.1. Nothing else.
- `Directory.Build.props`: `Nullable` enable, `TreatWarningsAsErrors` true, `LangVersion` latest.
- All sounds are synthesized by our own code. No third-party samples, logos or trademarks.

## Public signatures (DegaussNG.Core)

```csharp
public sealed record AppConfig
{
    public bool DegaussEnabled { get; init; } = true;
    public bool ReducedMotion { get; init; } = false;
    public double Volume { get; init; } = 0.3;
    public string Hotkey { get; init; } = "Ctrl+Alt+D";
    public AppConfig Normalized(); // Volume clamped to 0..1, invalid Hotkey replaced by the default
}

public sealed class ConfigStore
{
    public ConfigStore(string filePath);
    public static string DefaultPath { get; } // %APPDATA%\DegaussNG\config.json
    public AppConfig Load();
    public void Save(AppConfig config);
}

[Flags] public enum HotkeyModifiers { None = 0, Alt = 1, Ctrl = 2, Shift = 4, Win = 8 }

public readonly record struct HotkeyGesture(HotkeyModifiers Modifiers, uint VirtualKey)
{
    public static bool TryParse(string? text, out HotkeyGesture gesture);
    public override string ToString(); // canonical order: Ctrl+Alt+Shift+Win+Key
}

public readonly record struct DegaussFrame(double Amplitude, double RgbShift, double Brightness, double Phase);

public static class DegaussEnvelope
{
    public const double DelaySeconds = 0.12;
    public const double DecaySeconds = 1.78;
    public const double TotalSeconds = DelaySeconds + DecaySeconds; // 1.90
    public static DegaussFrame At(double seconds, bool reducedMotion);
}

public sealed class RunGate
{
    public bool TryEnter(); // true for exactly one caller until Exit
    public void Exit();
}
```

## Behaviour

### Config

- `Load` returns defaults when the file is missing.
- A corrupt file is moved to `config.json.bak`, defaults are returned, and no exception escapes.
- `Save` writes a temp file in the same folder and then replaces the target, creating the folder
  when needed. JSON is indented.
- Every loaded config passes through `Normalized()`.

### Hotkey

- `HotkeyGesture.TryParse` is case-insensitive, accepts the modifiers Ctrl, Alt, Shift, Win, and
  keys A-Z, 0-9 and F1-F24. It requires at least one modifier and exactly one key.
- `HotkeyService` uses `RegisterHotKey` with `MOD_NOREPEAT` on an `HwndSource` message window.
- If registration fails, the tray shows a balloon naming the gesture and the app keeps running.

### Envelope

With `p = (seconds - DelaySeconds) / DecaySeconds`:

- Before the delay and from `TotalSeconds` on, every field except `Phase` is exactly 0.
- `decay = exp(-3.2 * p) * (1 - p)`.
- Normal: `Amplitude = 0.018 * decay`, `RgbShift = 0.006 * decay`,
  `Brightness = 0.22 * exp(-9 * p)`. Brightness is one single pulse and never rises again.
- Reduced motion: `Amplitude` and `RgbShift` are multiplied by 0.35, `Brightness` is always 0.
- `Phase = seconds * 38`.

### Shader

`Degauss.hlsl`, ps_3_0, entry point `main`. Constants: c0 amplitude, c1 rgbShift, c2 brightness,
c3 phase. Sampler s0. The horizontal offset is
`amplitude * (sin(uv.y * 34 + phase) + 0.45 * sin(uv.y * 91 - phase * 1.7))`. Red and blue sample
at offset plus and minus `rgbShift`, green at the plain offset. Sampling coordinates pass through
`saturate`. Output RGB is `color * (1 + brightness)`, alpha 1.

`ShaderCompiler` compiles the embedded source once at runtime through `D3DCompile` from the
system `d3dcompiler_47.dll` (P/Invoke, `ID3DBlob` as a COM interface) and caches the bytes.
No fxc build step and no compiled shader in the repo.

If compilation fails or `RenderCapability.IsPixelShaderVersionSupported(3, 0)` is false, the run
skips the overlay, logs the reason, and still plays the sound.

### Degauss run (`DegaussRunner`)

1. `RunGate.TryEnter`. A trigger during a running effect is ignored.
2. Capture every monitor first, in physical pixels: `EnumDisplayMonitors`, `GetMonitorInfo`
   (`rcMonitor`), `BitBlt` with `SRCCOPY | CAPTUREBLT`, `Imaging.CreateBitmapSourceFromHBitmap`,
   `Freeze`, then release every GDI handle in `finally`. No overlay exists during capture, so it
   can never photograph itself.
3. Create one `OverlayWindow` per monitor, start the sound, drive the effect from
   `CompositionTarget.Rendering` with a `Stopwatch` and `DegaussEnvelope.At`.
4. At `TotalSeconds`, or on any exception, close all windows, detach the rendering handler, drop
   the bitmaps and call `RunGate.Exit`. All of this happens in a `finally` path.
5. Watchdog: an independent `DispatcherTimer` at normal priority force-closes everything after
   5 seconds, regardless of the state of the render loop.

`OverlayWindow` is a code-only WPF window: `WindowStyle.None`, `ResizeMode.NoResize`, `Topmost`,
`ShowInTaskbar` false, `ShowActivated` false, `AllowsTransparency` false, with an `Image` using
`Stretch.Fill`. In `SourceInitialized` it adds `WS_EX_LAYERED | WS_EX_TRANSPARENT |
WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`, calls `SetLayeredWindowAttributes(hwnd, 0, 255, LWA_ALPHA)`,
and places itself with `SetWindowPos` on the physical monitor rectangle using `SWP_NOACTIVATE`.
`app.manifest` declares `PerMonitorV2` DPI awareness.

### Sound (`tools/SoundSynth`)

`dotnet run --project tools/SoundSynth -- assets/sounds` writes `degauss.wav`. `DegaussSound.Render()`
returns `short[]`, 44100 Hz, 16-bit PCM, mono, exactly 2.2 seconds (97020 samples).

- 0 to 40 ms: relay clack. A 3 ms noise burst plus a 1800 Hz ping decaying within 35 ms.
- From 120 ms: the thump. Base frequency glides from 70 Hz to 50 Hz over the first 200 ms, then
  stays at 50 Hz. Add harmonics at 2x, 3x, 4x, 5x and 6x with audible level, because notebook
  speakers cannot reproduce 50 Hz itself. Exponential decay over the remaining time, with a quiet
  low-passed noise bed for the coil and power-supply character.
- Peak-normalize to -3 dBFS. A 50 ms linear fade-out makes the last sample exactly 0.
- Noise comes from an own xorshift32 generator with a fixed seed. Output is byte-for-byte
  reproducible. `System.Random` is not used.

`SoundPlayer` plays the embedded WAV with `WaveOutEvent` at `AppConfig.Volume` and disposes all
NAudio objects on `PlaybackStopped`. A missing audio device is logged and never fails the run.

### Tray

Menu, in order: `Degauss now`, separator, `Degauss enabled` (check), `Reduced motion` (check),
`Volume` (submenu 10, 30, 50, 70, 100 percent, radio style), `Change hotkey...`, separator, `Exit`.
Every change is saved at once and applies without restart. `Degauss enabled` off makes the hotkey
do nothing, while `Degauss now` still works. `TrayIconFactory` draws a small CRT icon in code and
destroys the native icon handle on exit. `HotkeyDialog` captures a key combination, shows it as
text, and saves only on OK.

A named mutex allows a single instance. A second start exits silently. Unhandled exceptions are
appended to `%LOCALAPPDATA%\DegaussNG\degauss.log` and close any overlay.

### Self-test

`DegaussNG.exe --selftest <cycles> <logPath>` runs without tray, hotkey, sound or config access.
It performs `<cycles>` complete degauss runs in sequence. After cycle 3 it forces a full GC and
takes a baseline, and after the last cycle it measures again. It writes exactly one line to
`logPath`:

`cycles=<n> failed=<n> gdiDelta=<n> userDelta=<n> privateDeltaMB=<n.n>`

Exit code 0 only when `failed=0`, `gdiDelta <= 5`, `userDelta <= 5` and `privateDeltaMB <= 40`.
The self-test ignores the single-instance mutex.

## Acceptance criteria

- AC1: Given a clean checkout, when `dotnet build -c Release` runs, then it succeeds with 0 warnings.
- AC2: Given a missing config, when loaded, then Volume is 0.3, Hotkey is `Ctrl+Alt+D`, ReducedMotion
  is false. Given corrupt JSON, when loaded, then defaults return and `config.json.bak` exists.
  Given Volume 7, when loaded, then Volume is 1.
- AC3: `ctrl+alt+d` parses and renders as `Ctrl+Alt+D`. `D`, `Ctrl+Alt` and `Ctrl+Foo` fail to parse.
- AC4: The envelope is 0 at t=0 and at TotalSeconds. Amplitude never rises after its peak.
  With reduced motion, Brightness is 0 at every sampled time and Amplitude is at most 35 percent of
  the normal value.
- AC5: `RunGate` admits exactly one of 100 parallel callers until `Exit`.
- AC6: `Render()` returns 97020 samples, is identical across two calls, matches the committed
  `degauss.wav` data, peaks at or below -3 dBFS, ends in 0, and RMS of the last 100 ms before the
  fade is below one tenth of the RMS between 200 and 400 ms.
- AC7: `DegaussNG.exe --selftest 20 <log>` exits 0 on a desktop session.
- AC8: The overlay closes within 5 seconds in every code path, including exceptions.
- AC9 (manual): The hotkey triggers while another app has focus. The effect covers both monitors at
  mixed DPI, clicks pass through, and focus does not change.
- AC10: CI on `windows-latest` runs restore, `dotnet build -c Release`, and `dotnet test -c Release
  --no-build`. The self-test is not part of CI.

## Do NOT

- No release or publish workflow.
- No additional NuGet packages and no additional projects.
- No files outside the Files section.
- No mention of tools, assistants or automation in code comments or documents.
